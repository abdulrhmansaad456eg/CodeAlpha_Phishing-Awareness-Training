# Phishing Awareness Training Module

## Overview
This project is part of the CodeAlpha Cyber Security Internship. It is an interactive, web-based training module designed to educate users about phishing attacks, how to recognize them, and best practices for staying safe online.

## Features
- **Educational Modules:** Covers Phishing Types, Red Flags, and Social Engineering.
- **Real-World Case Studies:** Provides context with famous phishing incidents.
- **Interactive Quiz:** Tests the user's knowledge with immediate feedback and score tracking.
- **Responsive Design:** Professional and accessible across different devices.

## Technologies Used
- HTML5
- CSS3 (Custom styling and animations)
- JavaScript (Vanilla JS for navigation and quiz logic)
- Font Awesome (Icons)

## How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/abdulrhmansaad456eg/CodeAlpha_PhishingAwareness.git
   ```
2. Open `index.html` in any modern web browser.

## Project Structure
- `index.html`: The main structure of the training module.
- `style.css`: The visual styling and layout.
- `script.js`: Interactive functionality and quiz logic.
